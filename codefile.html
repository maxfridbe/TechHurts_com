CodeFile — native code, data and diff viewer for Android

Opening a source file, patch or config file on a phone usually lands you in a bloated editor that wants an account or a clunky WebView wrapper. CodeFile (com.TechHurts.CodeFile) is a dedicated, read-only native viewer built on Android Views and the Sora CodeEditor widget — with an Office-style collapsing ribbon that adapts to phones, tablets, split-screen and foldables.

What it does
  • Open from anywhere. Pick up to 20 files (up to 8 MiB each, UTF-8 or BOM-marked UTF-16), share text from any app, tap Clipboard to open copied code with automatic two-stage language sniffing (LanguageSniffer), or open a public github.com/…/blob/… or raw.githubusercontent.com link directly.
  • 68 languages, 14 paired themes. Bundled TextMate grammars interpreted by a Java highlighting engine, paired light and dark themes, embedded JetBrains Mono and Fira Code Nerd Fonts, pinch zoom (8–40sp), fit-width reflow, bracket matching, block guides and whitespace markers.
  • Native previews & trees. A contextual ribbon tab appears for the open format: native Markdown rendering, expandable Tree view for JSON, JSONC, JSON Lines, YAML, TOML, INI, .properties/.env and XML, Table view for CSV/TSV/delimited files, and Diff view for .diff / .patch files.
  • Visual comparison & formatting. Compare any two open tabs unified or side-by-side and export a patch. Format brace languages, JSON, JSONL, YAML (preserving comments and anchors), XML and CSV/TSV with original source-line references in the gutter.
  • Local symbol navigation. Jump to symbols, definitions and references using an embedded JavaParser for Java and a local lexical index for other languages.
  • Syntax-highlighted PDF export. Share the whole document or a highlighted selection as a paginated vector PDF preserving syntax colours, theme background, font, line numbers and source references in A4, Letter, Legal, A5, A6, B5, Executive or Tabloid.
  • Optional AI snippet analysis. Point Settings at any OpenAI-compatible endpoint (OpenRouter, local Ollama, LM Studio, or your own LAN server). Only the snippet you preview and explicitly send is transmitted.
Privacy, specifically
  • ✓Documents stay on your device. Highlighting, formatting, Markdown, trees, diffs, symbol indexing and PDF rendering all run locally in Java.
  • ×No WebView, no telemetry, no ad SDK. CI runs an automated audit script (audit-native-apk.py) that rejects the build if any WebView class reference or browser asset slips into the APK.
  • ×No background traffic. The network is touched only when you open a public GitHub file link or tap Send on an AI snippet preview. Redirects are refused.
  • ✓Android backup & extraction disabled. allowBackup="false", and any optional API keys for your own endpoints are encrypted with Android Keystore.
Permissions, and why
Internet The only permission in the manifest. Used solely when you open a public GitHub link (fetched directly from raw.githubusercontent.com over HTTPS) or when you explicitly send a previewed snippet to an AI endpoint you configured.
Not requested Storage permissions (uses the system document picker and Android Share intents). Contacts. Location. Microphone. Camera. Notifications. Background services.
Open source & licences

CodeFile is built on AndroidBase. The Sora editor component is unmodified LGPL-2.1-or-later and its complete source archive is bundled inside the repository at third-party/source/ so you can modify and relink it offline. Syntax grammars come from VS Code extensions (MIT) and SnakeYAML Engine (Apache-2.0); every notice is readable inside the app under Support → Open-source licenses.
