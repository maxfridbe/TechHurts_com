TechHurts Widgets — six home-screen tools, one pack or separate APKs

Most small utility widgets on Android exist to host an ad banner or harvest background location. These don't. Each widget is an independent Android library module packaged both as its own standalone APK and inside TechHurts Widgets (com.techhurts.widgets), a single install that puts all six in your launcher's widget picker.

The Six Widgets
WidgetPackage & SizeWhat it does
TechHurts Weather com.techhurts.weatherwidget
Resizable		 Current conditions and temperature straight from the US National Weather Service (weather.gov). Configured by zip code — never asks for GPS. Tap for a full 7-day forecast with copy-to-clipboard.
GOES East com.techhurts.goeseast
4×4 min		 Fetches the latest NOAA GOES-19 East GEOCOLOR satellite image every 10 minutes and keeps a rolling 24-hour buffer (~144 frames). Tap to play a full-screen 24-hour time-lapse loop, adjust crop, or export and share as MP4, GIF or WebP.
Himawari-8 / 9 com.techhurts.himawari8
4×4 min		 Fetches the newest whole-disk GeoColor frame from CIRA SLIDER (Colorado State University) every 10 minutes. Same rolling 24-hour history, full-screen animation player, interactive crop and MP4/GIF/WebP export.
TechHurts Calc com.techhurts.calculator
1×1 fixed		 A 1×1 home-screen tile that displays the calculator icon until you run a calculation, then keeps the last result auto-sized inside the cell. Tap to open the keypad; CE resets back to the icon, Close keeps the result on your home screen.
TV Remote com.techhurts.hisense_remote
1×1 to 4×5		 Local Wi-Fi remote supporting four protocols: Android TV / Google TV (v2 TLS PIN pairing on ports 6466/6467), Hisense Roku TV (ECP HTTP on port 8060), IP Control ASCII (TCP 8088) and IP Control HEX (TCP 5000). Includes mDNS/SSDP discovery, a drag-and-drop button grid editor with per-button colour overrides, app launch buttons, and Send to TV in Android's share sheet for links.
TechHurts Timer com.techhurts.timer
1×1 fixed		 A 1×1 countdown dial whose ring empties every second and turns red when ringing. Tap for hours/minutes/seconds, 1m/5m/10m/30m presets, and custom alarm audio (system alarm or any MP3 you pick). Backed by a foreground service plus an AlarmManager clock backstop so Doze never swallows your alarm.
One pack or individual APKs

Every GitHub release publishes seven signed APKs from the same commit and version number (YY.MMDD.###):

  • com.techhurts.Widgets — the all-in-one pack. Install this one file to get all six widgets in your launcher picker, plus a single app drawer entry with one-tap Add to home screen buttons.
  • Six standalone APKs (WeatherWidget, Calculator, GOESEast, Himawari8, AndroidTVRemoteControl, Timer) — if you only want one or two and don't want the others even present on your device. Content providers are namespaced per application ID, so standalone APKs and the pack can even be installed side by side.
Privacy & permissions, widget by widget

None of the widgets contain analytics, crash reporting, advertising SDKs, or accounts. Two of them (Calculator and Timer) never touch the network at all.

PermissionWhich widget & why
Internet Weather queries api.weather.gov for the zip code you typed. GOES East and Himawari fetch satellite frames from NOAA and CIRA SLIDER. TV Remote sends commands to the local IP address of your TV on your LAN. Calculator and Timer do not request Internet.
Exact alarm & boot GOES East and Himawari schedule their 10-minute frame fetch and restore it after a reboot. Timer uses an exact alarm clock so your countdown fires on time even if the phone is in deep sleep.
Battery optimization exemption Optional prompt in Weather, GOES East and Himawari so Android Doze does not freeze periodic widget updates.
Notifications, vibrate & foreground service Timer only: ticks the 1×1 dial once per second while a countdown is active and shows the ringing alarm notification with a Stop alarm button.
Not requested Location / GPS (Weather uses a zip code you type). Contacts. Camera. Microphone. Call log. Storage (custom timer MP3s use the system document picker with persisted URI grants).
Building it yourself

Like AndroidBase, the build runs inside a Podman or Docker container so the host needs no JDK, Gradle or Android SDK:

bash make.sh

That single script computes the daily YY.MMDD.### version, builds the container image, compiles and signs all seven APKs with your key, and drops them into output/.
